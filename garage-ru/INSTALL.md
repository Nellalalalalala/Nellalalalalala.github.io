# GARAGE: Bad Dream Adventure — русский перевод 1.0.0

Для Windows-версии Steam 1.270, приложение **1946430**, сборка **20618823**.
Нужна установленная игра этой версии. Перевод не содержит саму игру.

## Установка на Windows 10 и 11

1. Закройте игру.
2. Распакуйте ZIP целиком в отдельную папку, например в «Загрузки».
   Не запускайте установщик из окна просмотра архива.
3. Откройте **Install.cmd**. Установщик найдёт игру в библиотеках Steam.
   Если не найдёт, выберите папку **Garage Bad Dream Adventure**, где лежит
   **Garage.exe**. Папку **Garage_Data** выбирать не нужно.
4. Дождитесь сообщения «Русский перевод установлен».
5. Запустите игру обычным способом через Steam. В настройках выберите
   **«Русский»**. Если игра уже была открыта, обязательно перезапустите её.

Ничего дополнительно устанавливать не требуется. Установщик использует
**Windows PowerShell 5.1**, встроенный в Windows 10 и 11. Перевод не использует
Python, Linux, WSL, Proton, Wine, BepInEx, подмену DLL или сетевые сервисы.
Файлы перевода — готовые ресурсы Windows-версии Unity. Скрипт меняет только
файлы в **Garage_Data**, не трогает сохранения, реестр и исполняемые файлы игры.
PowerShell запускается с разрешением исполнения только для этого процесса;
системная политика выполнения скриптов не меняется.

Установщик проверяет совместимость до замены файлов. Если Steam обновил игру
или установлена другая модификация, он остановится с объяснением.
Полная проверка файлов Steam возвращает текущую официальную версию игры;
она не понижает версию до 1.270. Для другой сборки нужен совместимый перевод.

## Удаление и возврат оригинала

Закройте игру и запустите **Restore.cmd** из распакованного пакета.
Оригинальные файлы сохраняются при установке в папке игры:

```text
Garage_RU_Backup\20618823\
```

Не удаляйте эту папку, пока пользуетесь переводом. Повторная установка
не перезаписывает оригинальную резервную копию. При ошибке записи установщик
пытается отменить изменения текущей операции. Сохранения игры не изменяются.
Вместо Restore.cmd можно восстановить официальные файлы проверкой через Steam.

## Если папка игры не определяется автоматически

В Steam: **Библиотека → Garage → Свойства → Установленные файлы → Обзор**.
Скопируйте путь к открывшейся папке. Из командной строки в папке пакета:

```bat
Install.cmd -GamePath "D:\SteamLibrary\steamapps\common\Garage Bad Dream Adventure"
```

Для проверки файлов без установки:

```bat
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Installer.ps1 -Action Verify -GamePath "D:\SteamLibrary\steamapps\common\Garage Bad Dream Adventure"
```

## Что переведено

3007 текстовых записей: диалоги и повествование, документы, названия предметов,
описания, достижения и интерфейс. Сохранены игровые команды, паузы, выбор ответов
и посимвольное появление букв. Исправлено размещение длинных начальных подсказок.
Для 35 плакатов добавлены русские подписи рядом с авторским изображением.

Официальное название на логотипе, имена авторов и участников титров оставлены
в оригинале. Рисунки плакатов и декоративные надписи окружения/видео не
перерисованы; нечитаемые стёртые участки не дополнены выдуманным текстом.

Перевод создан ИИ с контекстной редактурой, сверкой с японским текстом и
проверкой традиции перевода возможных философских отсылок. Это не работа
переводчика-человека. Принятые решения и источники — в **TRANSLATION_NOTES.md**.

## Состав пакета

- **Install.cmd / Restore.cmd / Installer.ps1** — установка и возврат оригинала.

- **manifest.json** — версия, совместимость и контрольные суммы SHA-256.
- **TRANSLATION_NOTES.md** — редакторские решения и источники.
